# quange-corpus · 全哥（北方的wolf1985）判据与语料索引

> 把全网公开内容炼成**逐条带出处、可复核**的人物判据体系。公开的是**索引、判据、方法与统计**；第三方原文只保存在本地。
> 状态：采集层完成、判据 v1（10 条）、言行回测未开始。更新：2026-11-09。

**在线浏览**：本仓库 `docs/index.html`（开启 GitHub Pages 后可见，也可直接下载双击打开，零依赖、离线可用）。

## 这个项目解决什么

不是给「全哥」做估值，而是把他在雪球、抖音、快手、YouTube 的公开表述，拆成可以回答「他会怎么判断」的判据：每条判据都有原话、出处、证据等级与衡量方式，避免把二手转述、家属/切片号内容、ASR 误识别当成他本人的观点。

## 为什么没有原始语料

雪球全文、短视频标题/转写、音视频均为第三方内容，本仓库**不包含**：既避免版权问题，也避免把未授权数据扩散。做法与同作者的 `buffett-corpus`（Index public, copyrighted full texts local only）一致。本项目也不需要凭据类文件，`ks_cookies.txt` 等一律不入库。

## 本地复现（想自己用）

1. 准备好自己的语料目录（雪球纯文本 txt、直播转写 txt）。
2. `python scripts/quange_search.py "现金流" --scope all --limit 20`
3. 把 `docs/criteria.json` 喂给任意 AI，配合 `docs/method.md` 的证据规则当 system prompt。
4. 用 `scripts/dedup_engine.py` 复算跨平台去重。

## 方法与边界

- **信源分级**：一手原文 > 平台索引 > 第三方转述；未标源数字单独归入「待核实」。
- **ASR 护栏**：转写未经人工回听不得标 `person_verbatim`（见 `docs/method.md`）。
- **账号隔离**：家属号、助理号、第三方授权切片号内容不进主库；转述巴菲特/段永平标「师承转述」。
- **未完成项**：判据候选池约 500 条待 v2；`track-record` 言行回测尚未开展，不可解读为「已验证无偏差」。
