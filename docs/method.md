# 方法与证据规则

## 1. 信源呈现规范

1. 每条数据必须带来源标签；
2. 按信源分组排版，不按数值大小或时间先后混排；
3. 显式注明口径差异（评价标准 / 统计范围 / 时段）；
4. 未标源的数字单独归入「待核实」，绝不与已归因数据并列成一张表；
5. 权威性：一手原文 > 平台索引 > 第三方转述 > 未标源叙述。

## 2. 证据枚举

| 值 | 含义 | 允许的用法 |
|---|---|---|
| `person_verbatim` | 本人原话，且有明确 source_refs | 可作判据主证据 |
| `person_implied` | 由行为/上下文推断 | 必须标注「推断」，不得写成原话 |
| `editor_analyst` | 整理者分析 | 只作解释，不作本人观点 |
| `practice_derived` | 实践归纳 | 需另附原始记录 |

## 3. 硬护栏

- **ASR 护栏**：`source_refs` 指向直播/ASR 转写且标 `person_verbatim` 视为错误 —— 未经人工回听最高只能标 `person_implied`。
- **verbatim 必须有原文出处**；`gate` 级判据必须有判定规则与不通过时的回退。
- **账号隔离**：19 个账号中含本人主号/小号、家属号、助理号、第三方授权切片号；后三者内容独立成库。已知污染率：念观众留言约 2.5%、ASR 崩坏段约 0.5%（来源：person-forge `quange.preset.json`）。
- **师承转述**：转述巴菲特/段永平的内容不算本人原创。

## 4. 去重规则

规范化标题 + 时长 ±3s + 发布时间三重指纹；双日期时须同日命中。保留优先级：`youtube_stream > youtube > douyin > douyin_lufei > kuaishou`。结果见 `data/dedup-report.md`。

- 言行回测 / track-record；
